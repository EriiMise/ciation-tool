# ciation-tool
# 文献格式管理工具

一个基于 AI 的学术文献引用格式自动生成工具，支持 APA、MLA、Chicago、GB/T 7714 等格式。

## 在线体验

👉 [点击直接使用](https://你的用户名.github.io/citation-manager/)

无需安装，打开即用。需要自备 AI API Key（支持 Claude、DeepSeek、Gemini、豆包）。

## 本地部署

1. 下载 [index.html](./index.html)
2. 双击用浏览器打开
3. 在设置里填入你的 API Key 即可使用

## 功能

- 支持 PDF 上传自动提取文献信息
- 支持期刊、书籍、报纸、网页、官方文件五种类型
- 支持自定义引用格式
- 数据本地存储，不上传任何文件到服务器
